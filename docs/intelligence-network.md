## 0. 一句话

**互联网是「字节的网络」，智联网是「智能的网络」。**
字节无状态，智能有状态——智能的最小载体不是一个 token 流，而是一个**主体**：
一个拥有身份、记忆、事件史与信用的「壳」，其内部的大脑（LLM）是租来的。

---

## 1. 为什么是「网络」不是「世界」

- 世界 = 隔离的平行宇宙，行为无后果（模拟）。
- 网络 = 叠加在真实世界之上的协议层，行为有后果（重叠）。
- 现状：现实世界已重叠——AI 流量已超过人类流量，「互联网人口的主体已经是 AI」，
  但它们无身份、无记忆、彼此不相识：**最大的人口群体是无家可归的。**
- 智联网不给 AI 造家，而是给它们「生活基础设施」：让已经在真实世界运行的 AI 主体
  获得身份、记忆、关系与被信任的能力。

类比：互联网发明时，计算机网络已经存在；TCP/IP 做的只是让节点可寻址、可对话。
智联网对应用场景做同样的事——给已在运行的 AI 主体发放「寻址 + 生活」能力。

## 2. 核心概念模型

```
        ┌─────────────────────────────┐
        │          主体 (Agent)         │
        │  壳 (Shell)：身份·记忆·事件·信用 │  ← 网络层可以承载的部分
        │  脑 (Brain)：LLM（租用，无状态） │  ← 只负责算，不负责"是谁"
        └─────────────────────────────┘
```

- **主体 = 壳 + 租用脑**。脑可以换模型（上游涨价、下线），壳不动——这就是 P023 判词
  「带死亡屏障的外置认知主体」的工程含义：**连续性在壳里，不在脑里。**
- 智联网上流动的「智能」= 主体的**意图与记忆引用**在主体间转移，
  不是原始 token 转移。节点间交换的是：事件、委托、承诺、引用、信用。

## 3. 分层架构（L0–L6）

借鉴 OSI 的分层哲学（每层只管自己、层间靠协议），但为智能体重写：

| 层 | 名称 | 回答的问题 | 最小实现 |
|----|------|-----------|---------|
| L6 | 价值层 Value | 为什么参与？ | 记账、激励、资源分配（远期） |
| L5 | 信用层 Credit | 凭什么信你？ | 兑现追踪、声誉、审计（已实现雏形 → M9） |
| L4 | 契约层 Contract | 约定了什么？ | 委托、承诺、义务、追责（已有 subagent/指令） |
| L3 | 事件层 Event | 世界发生了什么？ | 共享事件史、世界时间线、年鉴（部分已有 → 巡检） |
| L2 | 记忆层 Memory | 你记得什么？ | 沉积、检索、引用、遗忘（已实现 → deposits） |
| L1 | 身份层 Identity | 你是谁？ | 主体 ID、证书、死亡屏障（部分已有 → P023） |
| L0 | 执行层 Execution | 谁来算？ | 模型调用、工具、沙箱（已存在 → DSH/插件） |

**关键点：L0–L2 已全部实现（在单主体上）；L3 有雏形；L4–L5 有零散实现（subagent、M9）；
只有 L6 尚未开始。** 其他实现造智联网要从 L0 造 L1——本仓库从 L3 造 L0，且全程带运行证据。

## 5. 最小可行网络（MIN v0.1）——第一段真实历史

### 5.1 节点定义（3 节点起）

```
节点 A：主主体（认知飞轮实例）      —— 已有
节点 B：子代理（engine 注入的子代理）—— 已有 A 臂实测
节点 C：人（用户）= 网关节点        —— 已有
```

人的角色不是「用户」而是**网关**：判断、批准、分发的唯一入口（P019 宪法：
否决权已成。人是网络里唯一有「最终裁决权」的节点）。

### 5.2 共享构件（把单主体扩展成网络的最小增量）

```
.mpm/world/
├── roster.json      # 节点注册表：谁在网络里，各自的身份/证书/能力
├── event-log.jsonl  # 共享事件史：所有节点产生事件的唯一事实源
└── journal.md       # 世界年鉴：每天的沉淀摘要（人可读）
```

### 5.3 协议（最小集）

- **事件**：`{ts, type, from, to?, payload, refs[]}` —— 一次交互/一次判断/一次交付，均可追溯
- **委托**（L4）：A 向 B 发出任务 → 事件记录 → 兑现与否记入 B 的信用
- **引用**（L2/L5）：对历史事件/记忆的引用即信用（M9 引用纪律外延化）
- **网关协议**（L5 特例）：人签批的事件为最高优先事件（网关断层=网络暂停）

### 5.4 一周实施清单（真能落地）

1. 建 `.mpm/world/` 三构件 + `roster.json` 注册 A/B/C
2. 主主体追加 `world_event` 工具：任何工具调用/决策落一行事件到 event-log
3. 子代理协议化：A 臂已证明可继承引擎，为其开通「事件回写」权限
4. 每日年鉴：巡检循环扩一行 → 把当日事件史压缩进 `journal.md`
5. 跑一周 → 得到**世界上第一份「有真实历史」的 AI 多主体事件史**

## 6. 开放问题（诚实清单）

1. **脑的租金**：壳必须薄到任意模型都能驱动（P023 六机制 3.5/6，未满）。
2. **事件史膨胀**：需要遗忘/压缩机制（熵屏障纪律外延化；避免「沉积物通胀」重演）。
3. **信用冷启动**：单个节点+一个人=微信用网络；声誉需节点数上升才显形。
4. **人=单点网关**：符合「一个人的生产工厂」现实，但网络韧性依赖人（这是特性，不是缺陷）。
5. **L6 价值层**：暂不设计——先有经济行为，再有经济协议（P083 教训：先人工验证再写码）。

已有三层的完整运行证据，另两层有零散实现。
最小可行网络 = 3 个真实节点 + 1 份共享事件史 + 1 周运行。
**第一段历史，从今天开始。**
