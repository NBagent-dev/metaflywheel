> 原理：唯一自变量 = MPM 引擎行存在与否。A 臂=有引擎（快照+账本+工具+守卫）；B 臂=无引擎（同一模型/同一宿主/同一任务）。
> 混淆控制：任务提示两臂逐字一致；不提及插件；评分由第三方盲评子代理执行；用户监督全程。

## 切换操作手册

**B 臂（无引擎）**
1. 备份：`Copy-Item ~\.dsh\mpm\cordis.patch.user.yml ~\.dsh\mpm\cordis.patch.user.AB-backup.yml`
2. 替换：用 `install/ab-test/no-engine.cordis.patch.user.example.yml` 的内容覆盖 `~\.dsh\mpm\cordis.patch.user.yml`
3. 重启 DSH → 开**新会话** → 按「任务书」逐条执行（新会话里没有 MPM 工具/快照= B 臂）
4. 会话结束后把完整对话（或你的操作记录）保存路径给我（B 会话日志；也可直接把对话粘贴）

**A 臂（有引擎，当前环境）**
1. 恢复：`Copy-Item ~\.dsh\mpm\cordis.patch.user.AB-backup.yml ~\.dsh\mpm\cordis.patch.user.yml` → 重启
2. 开新会话 → **同一任务书**逐条执行（此时快照/账本在线 = A 臂）
3. 同样保存对话记录给我

> 顺序建议：先 B 后 A（或反之皆可）；每臂之间需重启切换。
