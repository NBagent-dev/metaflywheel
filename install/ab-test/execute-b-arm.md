   ```
   pwsh -ExecutionPolicy Bypass -File metaflywheel\install\ab-test\switch-b-arm.ps1
   ```

4. 完成后：把该会话完整对话保存/粘贴给我（或把输出保存为 `metaflywheel\install\ab-test\results\arm-B.md`）。
